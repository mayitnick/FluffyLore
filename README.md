# 🦊 FluffyLore — Пушистый редактор диалогов и Tellraw для Minecraft

Удобный веб-редактор сценариев и диалогов для лорщиков и создателей сюжетных карт/серверов Minecraft (версии 1.16–1.21+).

Позволяет писать диалоги в обычном человекопонятном формате, автоматически подставляет имена персонажей, цвета, оформление и мгновенно компилирует результат в готовые команды `/tellraw` с живым превью чата.

🌐 **Онлайн версия:** [mayitnick.github.io/FluffyLore](https://mayitnick.github.io/FluffyLore/)

---

## 🌟 Возможности

- **Разделенный интерфейс (Split View):**
  - **Слева:** Просторный редактор сценария с номерами строк, чистым моноширинным шрифтом и подсказками.
  - **Справа сверху:** Картотека персонажей, кликабельная палитра цветов Minecraft (`&0`–`&f`, стили `&l`, `&o`, `&n`, `&m`, `&k`, `&r`), выбор кастомных **HEX-цветов** (`&#ffaa00`), а также **🎮 живое превью чата Minecraft**.
  - **Справа снизу:** Поле экспорта готовых команд `/tellraw` с выбором селектора (`@a`, `@p`, `@s`, `@r` или кастомный), поддержка опции звука `/playsound` и форматов (команда, чистый JSON массив, §-legacy).
- **Свободное изменение размеров (Drag-to-resize):** Разделители между панелями можно перетаскивать мышкой в любое удобное положение.
- **Однокликовое копирование и экспорт:**
  - Кнопка «📋 Скопировать все команды».
  - Кнопка «💾 Скачать .mcfunction» (для быстрой загрузки в датапак сервера).
  - Сохранение и загрузка проектов в файл `.json`.
- **Автосохранение:** Все изменения, персонажи и настройки автоматически сохраняются в `localStorage` браузера — ничего не потеряется при случайном закрытии или обновлении страницы.
- **Анимация &k (Obfuscated):** Текст с кодом `&k` мерцает случайными символами в реальном времени точно так же, как в самой игре!

## 📝 Формат написания сценария

В левом поле вы можете писать диалоги самым простым способом:

```text
Сенко: Добро пожаловать домой, Вай! Чай уже готов~
Вай: Спасибо, Сенко! Как прошёл твой день?
*На плите тихо и уютно шумит медный чайник с жасминовым чаем*
Сенко: Всё замечательно! Садись скорее, я налила тебе полную чашку!
```

### Поддерживаемые элементы:
1. **Реплика персонажа:**
   - `Персонаж: текст`
   - `Персонаж » текст`
   - `Персонаж - текст`
   - При совпадении триггера имя заменяется на заданное в карточке (например, `&6&lСенко`), разделитель и базовый цвет реплики подставляются автоматически.
2. **Авторская ремарка / Действие:**
   - Строки в звездочках `*действие*` автоматически распознаются как ремарки рассказчика и окрашиваются курсивом (`&7&o`).
3. **Прямые цветовые коды прямо в репликах:**
   - Вы можете использовать классические коды Minecraft (`&a`, `&c`, `&6`...) или HEX-коды (`&#e67e22`), например:
     `Вай: Ого, это &eзолотое&r яблоко?`

## 🚀 Как включить GitHub Pages

Репозиторий уже настроен и залит на GitHub. Чтобы включить онлайн-сайт:

1. Откройте репозиторий: [github.com/mayitnick/FluffyLore](https://github.com/mayitnick/FluffyLore)
2. Перейдите в **Settings** ➔ **Pages** (в меню слева).
3. В блоке **Build and deployment**:
   - **Source:** `Deploy from a branch`
   - **Branch:** выберите ветку `main` и папку `/(root)`
   - Нажмите кнопку **Save**
4. Через 30-60 секунд сайт заработает по адресу:  
   👉 **[https://mayitnick.github.io/FluffyLore/](https://mayitnick.github.io/FluffyLore/)**

## 📦 Оффлайн использование (Standalone)

Если нужно передать редактор лорщику в виде одного файла:
- Файл `FluffyLore_Standalone.html` содержит в себе все стили и скрипты. Его можно отправить через Discord или Telegram — он открывается двойным кликом в любом браузере даже без интернета!
- Для повторной сборки автономного файла после изменений запустите:
  ```bash
  python build_single_file.py
  ```
